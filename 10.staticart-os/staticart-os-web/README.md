# StaticArtOS menu entry R1

Implements the five ordered StaticArtOS menu destinations defined in the StaticArtOS application menu design. Each route renders its real availability state. Virtual Exhibitions explains the CivilizationOS Exhibition Builder boundary and does not create a draft or move funding data into StaticArtOS.

Run `npm install --no-audit --no-fund` and `npm run check` inside this directory. The check typechecks, builds the app and exercises the rendered UI through a local HTTP server. Development: `npm run dev`. The web app is not yet connected to the Portal launcher or the authenticated CivilizationOS Exhibition Builder handoff.
